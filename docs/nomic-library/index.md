# Nomic library

What past Nomic games learned, collected for Promptocracy's players and its moderator. Each page covers one topic: where it comes from (links and short quotes of real rule text), patterns that worked, problems to avoid, and what it means for Promptocracy.

Notes marked "library note" are suggestions, not rules. Nothing here is a rule of any game until it passes as a proposal.
