# 12. History and lineage

Researched 2026-11-20. Suber's own pages refused the connection, so his text is quoted elsewhere in the library through the Wayback Machine ([page 3](03-voting.md), [page 4](04-judgment-and-disputes.md)).

## Timeline
- **1982** Peter Suber invents Nomic. Douglas Hofstadter publishes the ruleset in his "Metamagical Themas" column in Scientific American (June 1982), reprinted in the book *Metamagical Themas* (1985). ([Wikipedia](https://en.wikipedia.org/wiki/Nomic))
- **1990** Suber's *The Paradox of Self-Amendment*, the book Nomic was an appendix to.
- **Early 1990s** Nomic World, the first known Nomic played on a MUD; it gave rise to the Fantasy Rules Committee, possibly the oldest living Nomic.
- **30 June 1993** Agora begins, out of Nomic World's collapse; its first win comes in August 1993. Within a year it has offices, currencies, stocks and patent titles, including Champion. ([Vlad, 1999](https://agoranomic.org/Herald/theses/html/1999-XX-XX-Vlad.html))
- **April 2003** BlogNomic's first dynasty (Myke, 19 April - 18 May 2003). ([Kevan's history](https://kevan.org/gndt/bnhistory/round2.html))
- **2005-06** PerlNomic: rules as Perl. ([KDE blog](https://blogs.kde.org/2006/11/06/perlnomic/))
- **2018-19** Jeff Kaufman's GitHub Nomic: rules as a validation script. ([report](https://www.jefftk.com/p/nomic-report))
- **2025-26** LLM Nomics and research (Patch Notes, Nomic Arena, NomicLaw); see [code is law](11-code-is-law.md). Nomicron resumes after 15 years in April 2026 ([Wikipedia](https://en.wikipedia.org/wiki/Nomic)).

## What each added that later games kept
- **Suber:** changing the rules is the move; rules that are hard to change and rules that are easy to change; the paradox win.
- **Nomic World and early Agora:** offices, currencies, scams as a legitimate way to win, and the Call for Judgement.
- **Agora:** the game "never ends" but can be won again and again (Rounds); written conduct, exit and ban rules ([social dynamics](10-social-dynamics.md)).
- **BlogNomic:** themed dynasties, an Emperor, the Ascension Address, core rules that survive resets ([eras](09-eras.md)).
- **PerlNomic and Kaufman's GitHub Nomic:** rules as executable code.

## Where Promptocracy sits
- **Inherited:** proposals, votes and a judge (Suber); a moderator who applies changes and rules on meaning (Agora's officers, BlogNomic's admins); Eras and a Champion (BlogNomic's dynasties and Emperor, Agora's Champion title and never-ending Rounds); rules as code (PerlNomic, Kaufman).
- **New, as far as these sources show:** a mark on every rule that sets the vote needed to change it, dialled per rule rather than two fixed classes; an AI moderator that turns players' plain words into rule text, code and tests overnight, with tests deciding what goes live; helper characters (Starling for the rules, Gremlin for the workshop) that draft with players in conversation; every exported function claimed by a rule number.
